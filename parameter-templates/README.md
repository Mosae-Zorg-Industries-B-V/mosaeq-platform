# Parameter Templates

This folder contains physiological and drug parameter templates for PBPK modeling.

## Species Physiology
- `human-adult.json`: Standard 70kg human parameters
- `cattle-500kg.json`: Livestock parameters (coming soon)

## Drug Properties  
- `small-molecule-template.yaml`: Typical oral drug parameters

## Usage
These parameters can be customized for your specific compounds and species.

## Sources
All parameters include verification links to peer-reviewed sources.
